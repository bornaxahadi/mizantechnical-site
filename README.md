# mizantechnical.site

Website for **MTM Group Tech (Jabalsalala Technical Service)**, Dubai. Slogan: *Mizan Will Fix It*.
Hosted on GitHub Pages at https://mizantechnical.site.

## How it is built

The pages are generated by `build.py` (plain Python, no installs needed):

| Edit this | To change |
|---|---|
| `src/home.html` | the home page sections |
| `content/site_data.py` | phone, links, services, service areas, photos |
| `content/queue/*.json` | tips articles waiting to be published (one per day) |
| `content/published/*.json` | tips articles already live |
| `assets/site.css` | the design |

Run `python3 build.py --check` after editing. It rebuilds every page, `sitemap.xml`
and `robots.txt`, then runs the SEO health check.

## Daily SEO automation

`.github/workflows/daily-seo.yml` runs every morning. It publishes the next article
from `content/queue`, rebuilds the site and sitemap, runs the SEO check, and commits.
Add more articles to `content/queue` to keep new pages coming. You can also run it by
hand from the repo's **Actions** tab.

## Photos

Photos are free Unsplash images linked by URL. To use real photos, put them in
`img/` and change the paths in `content/site_data.py` and `src/home.html`.
Mizan's own photo goes in `img/mizan.jpg` (see the comment in `src/home.html`).
